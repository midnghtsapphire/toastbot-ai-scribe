# Security Policy

## Supported Versions

Security updates are applied to the latest active branch.

## Reporting a Vulnerability

Please report vulnerabilities privately via GitHub Security Advisories for this repository.

Include:
- Summary of the issue
- Reproduction steps
- Impact assessment
- Suggested remediation (if available)

We will acknowledge reports promptly and coordinate disclosure after remediation.

## Security baseline

- No secrets committed to source control
- User-supplied content must be handled safely and rendered as text by default
- Dependency updates should be reviewed regularly via npm audit and CI checks
